## Remaining structural work

These are documented design opportunities, not unresolved defects from the
2026-07-31 remediation:

- `chat-jobs.mjs` and `codesurfd.mjs` remain large transport/lifecycle modules.
  Extract only behind the now-behavior-tested contracts.
- `App.tsx` remains a large orchestration shell even after canvas interaction,
  persistence, drag, and tile-rendering extraction.
- Direct power extensions still carry ambient Node authority. The product and
  authoring docs disclose that trust boundary; a future broker migration can
  reduce it further.
- Node does not expose a portable directory-capability API equivalent to POSIX
  `openat` for every filesystem mutation. Canonical/handle revalidation is the
  implemented defense.
- Native Zig packaging/signing is target-specific and is not implied by the
  Electron, built-web, npm-package, or Electrobun gates.
