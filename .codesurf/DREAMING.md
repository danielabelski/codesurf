## Overview

CodeSurf (internal legacy name: contex) is an Electron desktop app providing an infinite 2D canvas workspace where humans and AI agents collaborate via tiles. Tiles are the universal unit: terminal, code editor, browser, kanban, chat, image, media, extension, and file viewers all live on the canvas. Agents connect over MCP or via direct provider subprocesses. All state is file-based (plus a new local SQLite DB); there is no cloud sync.

## Active Subsystems

### Canvas Engine (`src/renderer/src/App.tsx`)
- All 2D physics: pan/zoom, drag, resize, snapping, groups, undo/redo
- World coords = screen coords adjusted for zoom + pan offset
- Group movement recurses through nested groups
- Tiles are `React.lazy` + `Suspense` wrapped
- `canvasPointerWorld` is a `useRef` (not `useState`) — do not convert back to state; this prevents hot-path re-renders

### Event Bus (`src/main/event-bus.ts`)
- Main-process pub/sub with wildcard patterns (`tile:*`, `*`)
- Ring-buffer per channel (500 events); no persistence
- Bridges relay events to BrowserWindow instances via `win.webContents.send`
- 18 unit tests in `test/event-bus.test.ts`

### MCP Server (`src/main/mcp-server.ts`)
- Local HTTP MCP 2.0 server on a random port; 17 tools exposed
- Config written to `~/.contex/mcp-server.json` on start
- Agent results propagate to canvas/kanban via event bus
- MCP config IPC handlers extracted to `src/main/ipc/mcp-config.ts`

### Chat Providers (`src/main/chat/providers/`)
- **Claude** — `@anthropic-ai/claude-agent-sdk`, session resumption, adaptive thinking
- **Codex** — codex CLI subprocess (`providers/codex.ts`); `exec OPTIONS` must appear before `resume` subcommand on multi-turn
- **OpenCode** — `@opencode-ai/sdk` HTTP server (`providers/opencode.ts`)
- **OpenClaw** — `openclaw agent --json` subprocess; multi-turn sessions keyed by cardId (`providers/openclaw.ts`)
- **Hermes** — separate provider runtime (`providers/hermes.ts`)
- **Pi / csagent** — `src/main/chat/pi-runtime.ts`
- All providers stream via NDJSON/SSE parsed in `src/main/ipc/stream.ts`
- Provider sessions are isolated — do not share session IDs across providers or cardIds

### Prompt Conventions (`src/main/chat/prompt-conventions.ts`)
Injected into every provider (Claude, Codex, OpenCode, OpenClaw, Hermes):
- **`CODESURF_OUTPUT_CONVENTION`** — structured completion card (CHANGES MADE / DIDN'T TOUCH / CONCERNS); use only for substantial multi-file/risky work, not trivial edits
- **`CODESURF_INSIGHT_CONVENTION`** — `★ Insight ─────…` callout block; 1–2 bullets for non-obvious constraints or risks; never for routine summaries
- **`CODESURF_ACTIVITY_CONVENTION`** — use native todo/plan tools when available; neutral action language; short completion wording by default
- Pure helpers are unit-tested in `test/chat-convention-prompts.test.ts`

### Dreaming Daemon (`src/main/daemon/`, `src/main/ipc/dreaming.ts`)
- Daemon binary: `codesurfd.mjs`; managed via `@codesurf/daemon/manager`
- Version pinned to `@codesurf/daemon` package version (not Electron app version) to avoid TUI/desktop conflicts
- IPC channels: `dreaming:status`, `dreaming:listRuns`, `dreaming:run`, `dreaming:cancel`
- Version pin override: `CODESURF_DAEMON_VERSION_PIN` env var

### Omnigent Provider (Daemon) (`packages/codesurf-daemon/bin/omnigent-*.mjs`)
- Wire protocol: `POST /v1/sessions` (create), `GET /v1/sessions/{id}/stream` (live SSE, stays open), `POST /v1/sessions/{id}/events` (push user message/interrupt), `GET /v1/agents` (agent discovery)
- Default server: `http://127.0.0.1:6767`; default CLI: `omni`; model prefix: `omnigent:`
- `normalizeOmnigentServerRoot` strips trailing slashes and trailing `/v1` — callers may pass either server root or OpenAI-style `/v1` base
- Test coverage: `test/omnigent-desktop-wiring.test.ts`

### Harness Runtime (Daemon) (`packages/codesurf-daemon/bin/harness-runtime.mjs`)
